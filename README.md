# Portfolio

Personal site of Devyansh Agarwal. Built with Next.js, Tailwind CSS, Framer Motion and three.js (react-three-fiber).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `src/app`: layout, global styles, the single page
- `src/components`: sections and the 3D scene
- `src/data`: all content (projects, paper, skills, timeline). Edit text here.
- `src/lib`: small browser capability hooks (reduced motion, WebGL)
